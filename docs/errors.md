# Error catalogue

Generated by `tools/gen_errors_doc.py` from `src/ginn/errors.py`. Do not edit by hand.

Placeholders in braces, such as `{name}`, are filled in at run time.

Exit status 125 is not used by any code below. `ginn exec` returns the inner command's exit status, so ginn-side failures of `exec` and `enter` exit 125 instead (IR-011, FR-049).

## Exit statuses

| Exit | Meaning |
|---|---|
| 0 | success. `GINN-W-*` warnings also keep 0: they are notices, not exceptions. |
| 1 | operational failure: GINN-E-PKG-MANAGER, GINN-E-DOCTOR-FAILED, GINN-E-ATTACH-FAILED, GINN-E-REALM-USER |
| 2 | input validation: usage, names, options, paths |
| 3 | not found: GINN-E-NO-SUCH-REALM |
| 4 | conflict with existing state: name taken, undo refused, unacknowledged host change, interrupted operation not yet recovered, a realm in a state its verb does not allow (GINN-E-REALM-STATE) |
| 65 | data error (EX_DATAERR): image or package signature not verified |
| 69 | network failure |
| 70 | internal error (EX_SOFTWARE) |
| 73 | not enough disk space |
| 75 | realm, subordinate ID file or Host Setup busy, or a service still running at undo (EX_TEMPFAIL) |
| 77 | Host Setup must run as root, has not run for this user, or refuses an unsafe path it cannot repair (EX_NOPERM) |
| 125 | reserved; see EXEC_GINN_FAILURE |
| 130 | interrupted by the user |
