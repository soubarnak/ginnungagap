# ADR-NNN: Short decision title

- Status: Proposed | Accepted | Superseded by ADR-MMM
- Date: YYYY-MM-DD

## Context

Describe the forces behind the decision. Name the SRS IDs that create the constraint (for example, FR-011 or NFR-004). State which ranked characteristics from SRS section 4 apply, and in what order they settle the trade-off. Keep facts measured on the reference host separate from assumptions, and mark each assumption with the spike or task that will confirm it.

## Decision

State the choice in one or two short paragraphs, as a rule the code follows. Use "ginn does X" or "Code does X", not "X should be done".

## Alternatives considered

For each option not chosen: name it, state its benefit, and state the reason it was rejected. Keep the reasons specific.

## Consequences

List the results of the decision, positive and negative. State what the code must do and must not do. Name the follow-up tasks, spikes or ADRs that this decision creates or depends on. If a risk from SRS Appendix D applies, name it here.

## Requirement IDs

Every ADR cites the SRS IDs it decides for. Give one line for each ID that explains how this ADR bears on it.
